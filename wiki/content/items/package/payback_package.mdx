A **payback package** is a special type of [package](@envelope:package) that is used to send payment for a [payback](@envelope:payback_tag) request.\
Can be mailed.

## Obtaining
The only way to obtain a payback package is by packing a [payback box](@envelope:payback_box).

## Usage
![Payback Package interface](@envelope:gui/payback_package){width=352 right}

Payback Packages can be opened the same as regular [packages](@envelope:package).

Unpacking a payback package has a 75% chance to return a [payback box](@envelope:payback_box), allowing for another try at packing.

> [!NOTE]
> Unlike a regular [package](@envelope:package), payback package cannot be placed as a block.
